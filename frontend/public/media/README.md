# Media

Images used by the About page. Drop files here with these exact names and they
are picked up automatically:

| Filename        | Where it appears        | Ideal shape           |
|-----------------|-------------------------|-----------------------|
| `pipeline.png`  | About hero (in use)     | wide, roughly 16:9    |
| `slide.png`     | Motivation section      | a slide screenshot, 4:3 or 16:9 |
| `console.png`   | Closing section         | a screenshot of Overview or Run |

PNG or JPG both work. Next.js resizes and re-encodes them on request, so drop
the original resolution rather than a hand-shrunk copy.
