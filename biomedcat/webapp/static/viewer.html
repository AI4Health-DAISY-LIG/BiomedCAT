Context graph

Profile stratum. Each profile belongs to a granularity stratum (biochemical or clinical). Core classes are the Biolink classes that belong only to that stratum (for the biochemical stratum: transcripts, sequence variants, molecular activities, protein domains…). Shared classes are used by both strata but read from the stratum's angle (genes, proteins, small molecules, diseases, anatomy…). Outside groups the remaining classes (organisms, publications, generic things…). The uniform profile has no stratum: everything is "outside".
